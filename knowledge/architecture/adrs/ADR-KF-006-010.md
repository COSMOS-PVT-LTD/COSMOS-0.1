# Knowledge Foundation ADRs KF-006 through KF-010

**Authority:** Human Technical Owner — Tk Nayak  
**Status:** Accepted  
**Date:** 2026-08-23

These decisions close the remaining high-impact architecture items from the Knowledge Infrastructure Completion Master Plan. They do not modify frozen KG-BLOCK-001→013 implementation.

---

## ADR-KF-006 — Persistence architecture

**Decision:** The knowledge foundation persist layer is a **hash-verified JSON snapshot** of canonical payloads (IDs plus serialized law/correlation/property records) over in-memory typed repositories.

**Rationale:** A new database engine would duplicate the existing vault + repository architecture. Deterministic reconstruction is required; silent overwrite is forbidden.

**Consequences:**
- `dump_snapshot` / `load_snapshot` verify SHA-256 of the canonical payload.
- Full object graphs remain in typed repositories at runtime.
- A later production database may replace the snapshot file without changing repository contracts.

---

## ADR-KF-007 — Graph identity rules

**Decision:** Graph nodes use **opaque entity IDs already assigned by canonical models**. The concept graph stores relationships only. Typed graphs (equation, variable, component, …) are **views**, not separate stores.

**Rationale:** Duplicate graph stores would create competing identities. W6 already owns generic graph construction; KF typed views project that graph.

---

## ADR-KF-008 — Contradiction semantics

**Decision:** Conflicting numeric claims are retained as `ConflictRecord` objects. COSMOS **never silently selects** one source. Default `review_status` is `REVIEW_REQUIRED`. Optional `applicability_difference` records why both may still be valid.

---

## ADR-KF-009 — Validation authority

**Decision:** Machine-enforced `KnowledgeGovernance` roles authorize lifecycle mutation. Extractors emit **CANDIDATE** only. Production solvers consume **APPROVED** knowledge through `EngineeringQueryService` / `PhysicsKnowledgeGateway`.

---

## ADR-KF-010 — Uncertainty representation

**Decision:** Uncertainty is an `UncertaintyRecord` attached to the relevant entity or property value (`kind`, `magnitude`, `unit`, `notes`). It is not generic prose and is not an embedding score.
