COSMOS 0.1 Help

Local computational engineering application. Not flight-certified. Validation is NOT_CLAIMED unless a result envelope says otherwise.

Launch (native desktop)

COSMOS is a local installed application — its own window, not a browser tab. Install once, then launch:

pip install -r requirements-desktop.txt
python main.py

macOS: double-click scripts/launch_cosmos.command after dependencies are installed.

Do not use browser mode for normal work. Developer-only:

python main.py --browser

If pywebview is missing, install desktop dependencies and relaunch. A one-time browser fallback may appear with install instructions.

Login
